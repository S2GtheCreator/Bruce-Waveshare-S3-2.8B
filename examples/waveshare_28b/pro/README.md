# Visible, benign device tests

The exact same five files are embedded in BadUSB Pro > Install benign tests.
Installation asks for device approval and never overwrites an existing test file.
They are not auto-run and are not included in a filesystem flash image.

Use your own Windows computer. Turkish Q in Windows must match Turkish Q in Bruce.
01 opens visible Notepad and types TEST. 02 expects a focused empty Notepad.
03 visibly opens example.com. 04 opens and cancels the Run window, then types TEST.
05 waits 30 seconds: press Back/BOOT during the delay; no text should follow a stop.
Repeat text testing with English US selected in both Windows and Bruce.

No password/cookie collection, hidden command, elevation, or defense-disabling payload is added.
